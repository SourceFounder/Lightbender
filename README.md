## Features

- Adjust exposure, white balance, contrast, and colour.
- Build compositions with layers and blend modes.
- Make precise edits with brushes, gradients, and masks.
- Select skies and hair using local AI.
- Retouch small distractions with Heal and Clone tools.
- Automate supported editing tasks through a compatible MCP AI client.
